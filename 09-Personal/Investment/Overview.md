# 长期投资组合（从 0 开始）

> 适用范围：仅指未来 5～10 年以上不用的长期投资资金。应急金、日常现金，以及相机、手机、旅游等 1～5 年内需要使用的资金单独管理，不计入以下 100%。

| 资产类别 | 目标比例 | 可接受范围 | 组合中的作用 |
| --- | ---: | ---: | --- |
| 人民币高质量债券 | 30% | 25%～35% | 降低组合波动，并为再平衡提供稳定资金 |
| 中国宽基权益 | 25% | 20%～30% | 获取中国企业长期增长收益 |
| 海外广泛权益 | 35% | 30%～40% | 分散单一国家、市场和人民币资产风险 |
| 黄金 | 10% | 7%～13% | 应对通胀、货币与极端市场风险 |
| **合计** | **100%** |  | **权益 60%＋防御资产 40%** |

## 权益部分的内部结构

- 中国宽基权益：默认使用中证 A500，占长期账户 25%。如改用“沪深 300 20%＋中证 500 5%”，则不再同时持有中证 A500，避免重复配置。
- 海外广泛权益：美国宽基 25%＋美国以外发达市场宽基 10%。若平台暂时没有合适的低费率产品，可先用覆盖面较广的全球或海外宽基替代，不为凑齐品种而购买高费率基金。
- 科创 50、创业板指和行业主题基金不属于核心配置。未来如确实希望增加风格倾斜，应从中国权益的 25% 内划拨，合计不超过长期账户的 5%，不能额外提高总权益比例。

## 每月投入示例

以每月投入 10,000 元为例：

| 资产类别 | 每月投入 |
| --- | ---: |
| 人民币高质量债券 | 3,000 元 |
| 中国宽基权益 | 2,500 元 |
| 海外广泛权益 | 3,500 元 |
| 黄金 | 1,000 元 |

## 再平衡规则

- 每年 1 月和 7 月检查一次，不根据新闻或市场涨跌临时调整目标比例。
- 任一资产超出表中的可接受范围时，优先用后续新增资金补足低配资产。
- 只有仅靠新增资金无法在合理时间内恢复比例时，才考虑卖出高配资产进行再平衡。
- 不借钱投资，不使用杠杆，不动用应急金或短期消费资金加仓。
