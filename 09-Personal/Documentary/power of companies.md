# 公司的力量

Q1：**法国为什么能用密西西比公司、国债换股票、再配合大量印钞，去缓解本来很严重的政府债务问题？**
1. **债务重组**：允许使用法国国债购买公司股票 ->  债券关系转化为了股权关系。国债被消化
2. **资产价格泡沫**：通过推高公司股价，提高市场预期，促进债->股的转化。
3. **货币扩张**：增加货币总量，削减债务的实际分量。
==一旦股价过高、脱离基本面时，抛售情绪上涨，挤兑纸币，导致股价泡沫破裂，从而带来金融崩溃。==

Q2：政府印钞的实际作用是什么，新增的货币量怎么流入社会？
> [!info]
> 本质上不是国家印纸钞。**是中央银行创造新货币和购买力。** 新的钱是通过机制直接创造出来的。新增的货币通过以下途径流入社会：
> - 央行买国债：政府发行国债 -> 商业银行、企业购买 -> 央行从它们手中购买国债 -> 商业银行和企业获得现金 -> 流动性增加。
> - 央行给商业银行提供资金 -> 商业银行增加放贷数量 -> 企业和民众拿到贷款 -> 提高流动性
> - 政府财政支出：工资、基建、补贴、采购。。
