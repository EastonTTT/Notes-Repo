#浏览器进程模型
现代浏览器是多进程的应用。多进程能够提高web应用的稳定性、安全性、并发性以及性能表现。

## 浏览器渲染进程：
主要包含以下线程：
- GUI线程：负责渲染浏览器界面，解析 HTML，CSS，构建 DOM 树和 ROM 树，布局和绘制等，重绘（Repaint）、回流（重排）（reflow）
- JS线程：解析 Javascript 脚本，运行代码。**GUI 渲染线程与 JS 引擎线程是互斥的**，所以如果 JS 执行的时间过长，这样就会造成页面的渲染不连贯，导致页面渲染加载阻塞。
- 定时器线程：`setInterval`与`setTimeout`所在线程。浏览器定时计数器并不是由JavaScript引擎计数的,（**因为JavaScript引擎是单线程的, 如果处于阻塞线程状态就会影响记计时的准确**），因此通过单独线程来计时并触发定时（计时完毕后，添加到事件队列中，等待JS引擎空闲后执行）。
- 网络线程：处理`fetch,XHR`请求，转发给网络进程
- `IPC`线程：与其他进程进行通信
---
## 浏览器的渲染过程：
1. Html解析：接收HTML字节流 -> 解码+符号化 -> 构建DOM树，浏览器容错(标签不全)，同时触发预解析器（预加载CSS/JS/Image）**HTML是流式解析的**
2. Css解析：CSS规则树按从右向左。构建CSSOM树结构
3. Js编译执行：遇到`<script>`标签阻塞渲染 -> 先下载JS再执行（除非`async/defer`）
4. Render渲染树：DOM树与CSSOM规则树合并过程
5. 布局（重排）：根据 Render Tree 计算每个节点的 **几何位置和大小**
6. 分层：把页面元素放到对应的渲染图层中
7. 绘制（重绘）：把每个图层都转化为绘制指令集 -> 每个图层独立生成独立的像素图
8. 合成：把多个图层合成一个帧 -> 交给GPU渲染
---
### 细节补充：
#### DOM树的构建：
- DOM 树的构建过程是一个**深度遍历过程**：当前节点的所有子节点都构建好后才会去构建当前节点的下一个兄弟节点。DOM 树的根节点就是 document 对象。
- DOM 树的生成过程中可能会**被 CSS 和 JS 的加载执行阻塞。**
	- CSS的影响：只有等CSSOM构建完毕才能合成渲染树（CSS是异步下载的，并不会阻塞HTML的解析）
	- JS的影响：遇到`<script>`标签停止解析DOM和CSSOM -> JS可能会改动DOM和CSS -> 停止DOM和CSSOM的解析直到JS执行完毕
---
## 重排和重绘：
### 重排：
当修改了**元素的集合属性（宽、高、位置）或者增删DOM元素**的时候，浏览器会触发相关元素布局的重新计算。这个操作的性能开销很大 -> 会迫使浏览器重新走一遍**布局之后的渲染流程（布局 -> 绘制 -> 分层 -> 合成 -> 渲染）**
#### 怎么尽量减少重排？
- 用`classList`收集修改，把多次修改合并成一次样式计算（避免多次触发）
- 修改的时候加上`display:none`，修改完再显示（原理同上）
- 使用`createDocumentFragment()`，生成一个离线的DOM容器，在其中执行DOM操作，然后把操作一次性插入DOM树（原理同上）
- 使用`position:fixed/absolute`让元素脱离文档流，处于独立图层，不影响其他元素的布局
- 对于`scroll/resize`事件进行防抖、节流处理
---
### 重绘：
修改了元素的外观样式（颜色、背景、边框、阴影）时，浏览器把新样式重新绘制的过程。相较于重排操作，重绘**省去了布局和分层阶段**，所以执行效率会比重排操作要高一些。
***
### `<script>`标签 & JS：
浏览器在解析 HTML 的时候，如果遇到一个**没有任何属性**的 script 标签，就会暂停解析，先发送网络请求获取该 JS 脚本的代码内容，然后让 JS 引擎执行该代码，当代码执行完毕后恢复解析：
![[Pasted image 20250907134320.png]]
#### async script：
请求该脚本的网络请求是异步的，不会阻塞浏览器解析 HTML，一旦网络请求回来之后，如果此时 HTML 还没有解析完，浏览器会暂停解析，先让 JS 引擎执行代码，执行完毕后再进行解析：
![[Pasted image 20250907134430.png]]
#### defer script：
请求该脚本的网络请求是异步的，不会阻塞浏览器解析 HTML，一旦网络请求回来之后，如果此时 HTML 还没有解析完，浏览器不会暂停解析并执行 JS 代码，而是等待 HTML 解析完毕再执行 JS 代码：
![[Pasted image 20250907134538.png]]
