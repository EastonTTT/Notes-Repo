#CSS单位
# 单位与值：
## 绝对长度单位：
像素值 `px`  是一个绝对长度单位——与任何其他东西都没有关系，是一个客观的大小。
***
## 相对长度单位：
### em：
`em`的含义会根据**使用属性的不同而有所不同**，`em`应用在 **`font-size`** 上时，表示相对于父元素（HTML标签中直接包裹它的上一级标签）的大小，应用在其他属性上时，表示相对于**本级元素的`font-size`** 的大小。
注意⚠️：**==em的作用会随着嵌套逐级递增，可能会带来很大的变化==**
### rem：
**相对于根元素`font-size`的大小**
### 视口(viewport)：
**视口（Viewport）** 就是用户当前设备上==「能看到的网页区域大小，也可以理解为浏览器窗口的大小」==
**相关单位：**
- vw、vh：相对于视口宽/高的大小（==1vh/vw 占据视口宽/高的 1%==）
- `vmin`, `vmax`：取视口宽/高中较小/较大的部分
---
# 元素大小：
## 大小的设置：
常见的设置大小的属性：
- `height,width`：设置元素大小为固定值或者相对值（注意部分元素的`height`默认由内容撑开）
- `max-height,max-width`：限制尺寸范围，一般与`height,width`配合使用
- `min-height,min-width`：限制尺寸范围，一般与`height,width`配合使用
### max的注意事项：
当对某个元素设置`max-width: 100%`的时候，会限制元素的最大宽度为**父元素的宽度**，但**不会自动保持宽高比例（所以要设置`height: auto`）** 如果元素本身小于容器，则保持原尺寸不变。

### 内外边距的百分比：
一般属性的百分比都是**相对于父元素（或者父容器）的大小，所以要特别注意父元素有没有高度、宽度**
==特例：`padding` 和 `margin` 的百分比大小都是**相对于父元素的宽度 ==
