## 选择器：
**选择器（Selector）** 是 CSS 用来匹配 HTML 元素的语法规则。通过选择器，CSS 能对指定的 HTML 元素应用样式。
### 属性选择器：
属性选择器可以**根据元素是否拥有某个属性，以及该属性的值来选择元素。**
这里的 **“属性”** 指的是：**最终 DOM 中可见的 HTML 属性**
#### 用法：
属性选择器可以单独生效，也可以==配合其他选择器一起使用。==

| 语法              | 示例                  | 匹配对象             | 用法说明         |
| --------------- | ------------------- | ---------------- | ------------ |
| `[attr]`        | `[disabled]`        | 有 disabled 属性的元素 | 只要有属性就匹配，不看值 |
| `[attr="val"]`  | `[type="text"]`     | 属性值完全等于 `val`    | 精确匹配         |
| `[attr~="val"]` | `[class~="active"]` | 属性值中包含某个**单词**   | 多用于 `class`  |
| `[attr^="val"]` | `[href^="https"]`   | 属性值以 `val` 开头    | 前缀匹配         |
| `[attr$="val"]` | `[src$=".jpg"]`     | 属性值以 `val` 结尾    | 后缀匹配         |
| `[attr*="val"]` | `[data-id*="menu"]` | 属性值中包含 `val` 子串  | 子串匹配（位置不限）   |
以上用法配合各类选择器一样生效。
***
### 关系选择器：

| 组合符         | 名称                        | 作用                  |
| ----------- | ------------------------- | ------------------- |
| `A B`(空格隔开) | 后代选择器（descendant）         | 选择 A 元素**内部所有 B**   |
| `A > B`     | 子代选择器（child）              | 选择 A 元素**的直接子元素 B** |
| `A + B`     | 相邻兄弟选择器（adjacent sibling） | 选择紧挨着 A 的下一个 B      |
| `A ~ B`     | 通用兄弟选择器（general sibling）  | 选择 A 之后**所有兄弟 B**   |
这里的`A、B`可以是 html标签、类名等等
### 并列选择器：
 `A, B` （使用逗号隔开）：表示对命中选择器A和选择器B的所有元素都成立，**用于多个元素的样式复用**

## 伪类 & 伪元素：
### 伪类：
**定义：** 选中==处于特定状态==的元素，并给它添加指定的样式。（本质上是CSS样式层面上的更改，==不涉及DOM元素的操作==）
#### 常用伪类：
##### 交互相关：
- `:hover`：鼠标悬停
- `:active`：激活状态
- `:focus`：获得焦点（文本框等）
- `:visited`：链接已访问
##### 结构相关：
- `:first-child`：父元素的第一个子元素
- `:last-child`：父元素的最后一个子元素
- `:nth-child(n)`：父元素的第n个子元素（如果写的是形如`an+b`的表达式，则**会选中多个子元素**：**n从1开**始（如果表达式为n+1，就表示选择除了第一个子元素之外的所有子元素，以此类推...），**如果写的是单个值，那么只会选中一个子元素**）
- `:empty`：当某个元素没有子内容时
- `:only-child`：当某个元素有唯一子内容时
- `:not()`：
##### 表单相关：
- `:checked`：被选中状态（radio / checkbox...）
- `:disabled`：被禁用状态（button、input...）
