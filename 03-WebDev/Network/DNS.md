域名系统（Domain Name System）是互联网的一项服务。是将域名映射为IP地址的一个分布式数据库。
> [!info] info
> DNS 使用 TCP 和 UDP 端口 53。

## 工作流程：
```text
用户输入 URL 并按下回车
↓
浏览器解析 URL
  - 确定协议 (http / https / file …)
  - 拆解域名、端口、路径、参数
↓
浏览器检查缓存
  - 浏览器缓存
	  ↓
  - 操作系统缓存(hosts 文件)
  （若命中，直接得到 IP）
↓
DNS 解析
  - 向本地域名服务器查询（ip所在城市的总服务器）
	  ↓
  - 根服务器 → 返回 TLD 服务器地址
	  ↓
  - TLD 服务器 → 返回权威服务器地址
	  ↓
  - 权威服务器 → 返回最终 IP 地址
↓
得到服务器 IP 地址（结果会被保存到缓存中）
↓
建立连接
  - TCP 三次握手
  - 若是 HTTPS → TLS/SSL 握手
↓
浏览器发送 HTTP 请求
  - 方法 (GET/POST)
  - 请求头 (Host、Cookie…)
  - 请求体（如果有）
↓
服务器接收并处理请求
  - Web 服务器 (Nginx/Apache) 接收
  - 应用服务逻辑处理
  - 查询数据库 / 缓存
  - 生成响应内容
↓
服务器返回 HTTP 响应
  - 状态码 (200/301/404…)
  - 响应头 (缓存策略、类型…)
  - 响应体 (HTML/JSON/图片…)
↓
浏览器接收响应并处理
  - 解析响应头
  - 缓存策略判断
↓
浏览器渲染页面
  - 解析 HTML → 构建 DOM 树
  - 解析 CSS → 构建 CSSOM 树
  - 执行 JS → 操作 DOM / 发新请求
  - 合成渲染树 → 布局 (Layout) → 绘制 (Paint) → 合成 (Composite)
↓
页面呈现给用户
```
